# 🌍 TerraJourn - Seyahat Blogu ve Gezi Rehberi

**TerraJourn**, seyahat tutkunlarını bir araya getiren, kullanıcıların deneyimlerini paylaşabildiği ve kişiselleştirilmiş mekan önerileri alabildiği interaktif bir web platformudur.

## 🚀 Proje Hakkında
Bu proje, klasik bir blog sitesinin ötesine geçerek kullanıcı etkileşimi ve rehberlik hizmetini birleştirir. Kullanıcılar sadece okuyucu değil, aynı zamanda birer içerik üreticisidir.

Site temel olarak 5 ana modül üzerine kuruludur:
1.  **Ana Sayfa:** Vitrin ve öne çıkan içerikler.
2.  **Blog:** Kategori bazlı kullanıcı yazıları.
3.  **Rehber:** Kişiye özel mekan önerileri.
4.  **Hakkımızda:** Vizyon ve misyon.
5.  **İletişim:** Kullanıcı destek ve geri bildirim.

## ✨ Temel Özellikler

### 👤 Kullanıcı Deneyimi
* **İnteraktif Blog Sistemi:** Kullanıcılar kategorilere (Doğa, Gastronomi, Kültür&Tarih vb.) göre yazı yazabilir.
* **Sosyal Etkileşim:** Blog yazılarına yorum yapma ve tartışma ortamı.
* **Akıllı Rehber (Guide):** Kullanıcının tercihlerine göre yapay zeka tarafından sunulan özel mekan önerileri.
* **Güvenli Üyelik:** Kayıt olma, giriş yapma ve profil yönetimi.

### 🛡️ Yönetim (Admin) Paneli
* **Tam Kontrol:** Site üzerindeki tüm blog yazıları, yorumlar ve kullanıcılar admin tarafından yönetilebilir.
* **İçerik Denetimi:** Uygunsuz yorum veya yazıların silinmesi/düzenlenmesi.
* **İstatistikler:** Site içi hareketlerin takibi.

## 🛠️ Kullanılan Teknolojiler

Bu proje, **N-Tier Architecture** (Katmanlı Mimari) prensiplerine sadık kalınarak geliştirilmiştir.

| Alan | Teknoloji / Araç |
| :--- | :--- |
| **Backend** | C#, ASP.NET MVC 5 |
| **Veri Tabanı** | MS SQL Server Express |
| **ORM** | Entity Framework (Code First / DB First) |
| **Frontend** | HTML5, CSS3, JavaScript, Bootstrap |
| **Güvenlik** | Authentication & Authorization |
| **IDE** | Visual Studio 2022 |
